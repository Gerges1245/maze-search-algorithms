# 🧩 Maze Search Algorithms Visualizer

An interactive maze solver built with Python and Tkinter that visually demonstrates three classic AI search algorithms in real time.

## 📖 About

Draw any maze, place a start and goal, then watch BFS, DFS, or A* explore and solve it step by step with animated highlighting.

## 🛠️ Tech Stack

- **Language:** Python
- **GUI:** Tkinter (built-in)
- **Algorithms:** BFS, DFS, A\* with multiple heuristics

## ✨ Features

- 🎨 **Interactive grid** — draw walls by clicking and dragging
- 🚀 **3 search algorithms** — BFS, DFS, A\*
- 🧠 **A\* heuristics** — Manhattan, Euclidean, Chebyshev, custom per-cell
- ⚡ **Animated visualization** — watch exploration and path unfold
- 🌀 **Maze generator** — auto-generate random mazes
- 🔄 **Reset / Clear** controls
- 📊 **Stats panel** — nodes explored, path length, time

## 🚀 Getting Started

### Prerequisites
- Python 3.x (Tkinter is included in the standard library)

### Run
```bash
python maze_search.py
```

## 🎮 How to Use

| Action | How |
|--------|-----|
| Draw wall | Left-click drag |
| Set Start | Select "Start" mode → click |
| Set Goal | Select "Goal" mode → click |
| Run | Click **Run** button |
| Generate Maze | Click **Generate** |

## 🔬 Algorithms

| Algorithm | Complete | Optimal | Notes |
|-----------|----------|---------|-------|
| BFS | ✅ | ✅ | Shortest path guaranteed |
| DFS | ✅ | ❌ | Fast but not optimal |
| A\* | ✅ | ✅ | Fastest with good heuristic |
